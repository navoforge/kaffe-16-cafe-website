# Kaffe 16 website concept

A direct-open static website concept built with HTML, CSS and vanilla JavaScript. Open `index.html` in a browser; no installation, server or build step is required.

## Photography

The project folder contains 11 supplied JPEG photos beside `index.html`, all 900 x 600 pixels except `kaffe1611.jpg` at 900 x 601. The page uses `kaffe1610.jpg` for the hero, `kaffe1611.jpg` for the storefront, `kaffe163.jpg` and `kaffe162.jpg` for the space section, `kaffe164.jpg`, `kaffe168.jpg` and `kaffe166.jpg` for the menu cards, and `kaffe161.jpg`, `kaffe167.jpg` and `kaffe169.jpg` in the gallery.

The food card uses `kaffe166.jpg`, which shows coffee and plated desserts; it should not be presented as a savory meal. `kaffe165.jpg` is an alternate coffee-and-dessert photo not currently used. Images have descriptive alternative text, use `object-fit: cover`, and retain a labelled fallback if a referenced file is missing. Confirm photo usage rights before publishing.

## Verify before publishing

Replace visit details and menu categories with information confirmed by the business. Verify any official social account before linking it. This concept currently has no verified address, hours, contact details, menu items or social links.
